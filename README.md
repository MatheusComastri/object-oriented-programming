# Programação Orientada a Objetos com Python

Projeto desenvolvido para a prática dos principais conceitos de **Programação Orientada a Objetos (POO)** utilizando Python.

O projeto é composto por diferentes exercícios, cada um representando uma classe com seus respectivos atributos, métodos, getters e setters. Também foram desenvolvidos testes automatizados utilizando **pytest** para verificar o funcionamento das classes e seus métodos.

---

## Objetivos

O principal objetivo do projeto é praticar e consolidar conceitos fundamentais de Programação Orientada a Objetos, como:

- Criação de classes e objetos;
- Atributos e métodos;
- Encapsulamento;
- Getters e setters;
- Alteração do estado dos objetos;
- Validações e estruturas condicionais;
- Entrada de dados com `input()`;
- Retorno de informações com `return`;
- Exibição de informações com `print()`;
- Testes automatizados com `pytest`;
- Uso de `monkeypatch` para simular entradas do usuário;
- Uso de `capsys` para testar mensagens exibidas no terminal.

---

## Tecnologias utilizadas

- **Python**
- **PyCharm**
- **pytest**
